# Villager mockups: the Hearthfolk

Pixel-art concept mockups for villagers. The art is generated by `tools/mockups/build.py`
(`pip install pillow && python3 tools/mockups/build.py`).

| File | What it shows |
|---|---|
| `01_lineup.png` | Six villagers as in-game sprites (28x56, 3/4 view, about 6 heads tall) in a burrow hall |
| `02_portraits.png` | Close-up dialogue portraits (56x64 busts) that carry the facial detail |
| `03_culture_key.png` | Markers every villager shares: knot band, hearth token, dye palette |
| `card_*.png` | One card per villager: portrait, sprite, daily routine, reaction when struck, palette |

## Direction
- Grounded proportions and serious, neutral faces. No chibi heads and no smiles by default.
- Muted undyed wool and plant dyes (madder, moss, indigo-slate, walnut, ochre).
  Copper and amber are the only bright accents.
- Culture shows in repeated details, not costumes: the woven madder **knot band** on every sash and hem,
  and a copper **hearth token** worn at the neck.
- Each role has a clear silhouette prop (hammer, staff, bow, candle cap and pick, yarn basket, spear),
  so you can read a villager's job at 1x.
